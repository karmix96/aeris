## Findings that change decisions

**Pressure drag is carried by chordwise resolution.** `gci_C → gci_M` drops CDp by a constant
−0.00273 ± 6 % across three geometries and four incidences; CL, CDv, CMy and the neutral point
are converged. Refining one axis at a time recovers, of that gap:

| direction | cells | recovered |
|---|---|---|
| chord (`n_side` 45→58) | 744,828 | **88 %** |
| span (`n_span` 49→63) | 649,688 | 11 % |
| edges (LE/TE spacing) | 567,256 | 7 % |
| normal (`n_normal` 65→84, s0 held) | 733,316 | −15 % of CDp; total CD +1.7 counts (AUDIT C5) |

A chord-only level at `gci_F`'s chordwise ratio is ~975k cells / ~10 GiB and **fits this
desktop**, where `gci_F` (2.2M) does not. Whether chord-only *keeps* converging is being tested
now. Evidence: `reports/s8_directional_refinement.json`.

**RETRACTED — the AVL correction is NOT geometry-specific.** An earlier version of this file
said CFD−AVL CL varied 3.5× more across geometries than across incidence. That was defect 23:
every pilot geometry was solved against index 83's reference area, and their own areas differ
by −25 % to +31 %. Normalised correctly, CFD and AVL agree to about ±2 % on every wing, and the
multifidelity strategy looks viable. Full account: `AUDIT_2026-09-10.md`.

**The 1e-6 stopping rule holds** on three geometries unlike index 83: worst force movement
beyond it is 0.073 %, ~340× below the CDp signal. `reports/s8_l2_revalidation.json`.

**y+ is wall-resolved on every planform.** OML p99 0.68–0.83 across all ten. The y+ 3–5 in the
tables is the tip cap's 264 cells, by design.

**Meshing is deterministic.** 37/37 `compare_meshes` metrics identical across two independent
builds of index 83.

## Traps specific to this host

- Interpreters: the plan's `/home/mike/...` paths are another machine. Use `env_s8.py`.
- ADflow writes **ADF**, not HDF5. h5py reads nothing and says nothing. Use `cgns_read.py`.
- `*.png` and `*.sh` are gitignored — both need `git add -f`.
- Work on `main`. Pushes go over a repo-scoped deploy key with write access, added on 15 Sept:
  `~/.ssh/aeris_deploy`, selected for github.com in `~/.ssh/config`. `ssh -T git@github.com`
  answers "Hi karmix96/aeris!" when it works.
- Pilot run directories are `<level>_a<alpha>`. They were once `a<alpha>` with no level, and a
  second grid level silently skipped every run and then **mislabelled** the first level's forces.
- `printf` with a `%` in a commit message truncates it silently. Use a heredoc.
- **Defect 23 lives on in the RAW run files.** Only the archive was rescaled. Every pre-fix
  `result.json` of the nine non-reference geometries still divides by index 83's area. Any
  analysis that reads `result.json` across geometries must rescale by
  `area_ref_m2 / own_area` first -- `chi_offset.py` shows how. Read raw, the freestream
  turbulence study reported a 7 % change in LIFT from a setting that cannot move lift.
- **Reference area is per geometry.** `solve_s8.py`'s default is index 83's. `run_campaign.py`
  now passes each geometry's own from `reference_areas.json` and refuses one it doesn't have.
  Anything that calls `solve_s8.py` directly must pass `--area-ref` itself.
- `pkill -f PATTERN` kills your own shell when PATTERN appears in the command you typed.
  Kill by PID, found with a bracketed pattern: `ps -eo pid,cmd | grep "[p]rterun"`.
- Anything run beside a timing measurement contaminates it. `queue3.sh` exists because a
  "quick" NACA test ran beside the multigrid baseline.
- ANK alone stalls at line-search step 0.01 on the NACA 0012 case (all three ANK variants
  tried); ANK → NK with stronger preconditioners converges in 56 iterations. A stalled
  ANK run there sat at a relative residual near 3e-6 with CD still 1.8 % off.
- **The WSL VM itself can restart** (13 Sept 23:23, most likely memory, during SU2 on six ranks)
  and takes every job with it, `nohup` or not. Queues skip any run with a `result.json`, and a
  memory guard kills a run cleanly below about 2 GiB free.
- **Measure a mesh quantity on every span row, never on one picked by index.** Adding span rows
  near the tip moved `k = n_span // 2` from 93 % to 96 % semispan and flipped a guideline verdict.
- **Twist from a mesh:** chord line from the MIDDLE of the opened trailing-edge base to the
  farthest point. One corner reads 0.15° of false washout, and pyGeo's `u = 1` is not the
  leading edge for two of the three airfoils (extracted `twist_deg` reads up to 0.5° high).
- **SU2's `SURFACE_CSV` carries only the solution variables.** Skin friction, y+ and the
  pressure coefficient reach a file only through `SURFACE_TECPLOT_ASCII` or the ParaView surface
  writer, and asking for them through `VOLUME_OUTPUT= (..., PRIMITIVE)` is accepted, reported
  back as accepted, and still does not put them in the CSV. Stage 0's first three runs therefore
  could not be judged on their main criterion, cf at x = 0.97, and the wing's SU2 runs had the
  same hole. An unknown group name is *ignored with a note*, never refused, so this fails silently.
- **SU2 prints `Exit Success` even when a signal killed it.** The roe_wls numerics variant was
  killed at iteration 727 on 15 Sept; its log still ended with `Exit Success`, so a queue whose
  skip test was `grep -q "Exit Success"` treated it as finished and never re-ran it. Ask instead
  for `All convergence criteria satisfied` AND no `Interrupt signal` — `finished()` in queue21.sh
  and the `finished` field in su2_validation.py.
