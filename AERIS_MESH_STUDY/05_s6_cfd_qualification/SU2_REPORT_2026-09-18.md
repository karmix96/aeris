# SU2 in the AERIS project: what it is for, what was run, and what it has shown

Written 2026-09-18. Self-contained: it assumes you know what CFD is and nothing about what this
project has done with SU2. Every number is from a run on this machine unless it says otherwise.

---

## 1. Why there is a second solver at all

The AERIS design campaign runs on **ADflow**. SU2 exists here for two reasons, and they are
different reasons that are easy to conflate.

**Reason one — ADflow has no transition model.** It solves the flow as if the boundary layer were
turbulent everywhere, from the leading edge back. Real wings do not work that way: the boundary
layer starts laminar and *transitions* to turbulence somewhere, and laminar skin friction is
several times lower than turbulent. AERIS flies at chord Reynolds numbers of roughly
**0.8 to 1.2 million**, with the outer wing lower still. That is squarely in the range where
transition location is a first-order effect on drag, not a correction. SU2 ships the
**Langtry–Menter** transition model. Nothing else available to this project does.

**Reason two — one code is not a check on itself.** Two independently written solvers that agree
on the same grid at the same conditions tell you something a single solver cannot. They do not
tell you the answer is *right* — both can be wrong the same way — but disagreement is
informative and agreement is worth having.

A third reason people offer, that SU2 is widely used in industry, is not a reason to trust a
number. It is a reason to expect the code to be well tested, which is different.

## 2. How to read any result in this report

Three words get used loosely and mean different things. Everything below is labelled with one.

| term | means | does not mean |
|---|---|---|
| **Converged** | the iterations stopped changing the answer | the answer is right |
| **Verified** | our numbers match other codes' numbers on the same problem | the physics is right |
| **Validated** | our numbers match a physical **measurement**, within a stated uncertainty | the code is right everywhere |

Matching CFL3D and FUN3D on a flat plate is **verification**. Matching McGhee's wind-tunnel data
on the Eppler 387 is **validation**. Only the second says anything about nature, and only for that
airfoil at that Reynolds number.

## 3. What is installed, and every setting in force

**SU2 v8.5.0 "Harrier"**, built at `AERIS_MESH_STUDY/tools/su2_8.5.0`. Runs are launched under the
MACH-Aero environment's `mpirun`, two MPI ranks per case for these 2-D problems.

Nothing below was invented for this project. Every case starts from **SU2's own published tutorial
configuration** for that case, and the only things deliberately changed are output settings — which
files get written, and where. That is a policy, not an accident: it keeps the comparison honest
and means a disagreement with SU2's published result is ours to explain.

### 3.1 The settings that vary, and why

| setting | values in use | what it does and why it differs between cases |
|---|---|---|
| `SOLVER` | `RANS`, `INC_RANS` | Compressible or incompressible. **AERIS flies at Mach 0.084** — effectively incompressible — so the `INC_RANS` cases are the ones in our regime. The compressible cases exist because NASA's reference data for them does. |
| `KIND_TURB_MODEL` | `SA`, `SST` | Spalart–Allmaras is what **ADflow uses**, so SA cases are directly comparable to our production solver. SST is the other standard two-equation model and is what most Langtry–Menter examples pair with. |
| `KIND_TRANS_MODEL` | `LM`, none | Langtry–Menter. Present only on the transition cases; absent means fully turbulent, like ADflow. |
| `CONV_NUM_METHOD_FLOW` | `ROE`, `FDS`, `L2ROE` | The flux scheme — how the solver computes the transfer between neighbouring cells. **This matters more than it looks:** SU2's own documentation warns that the scalar `JST` scheme can overestimate viscous drag on low-Reynolds meshes, and we measured exactly that. `L2ROE` is a low-Mach variant used by the transition tutorials. |
| `MUSCL_FLOW` | `YES` everywhere | Second-order reconstruction. First order would be stable and useless for drag. |
| `SLOPE_LIMITER_FLOW` | `NONE`, `VENKATAKRISHNAN` | A limiter suppresses oscillations near sharp gradients at the cost of some accuracy. The flat plates need none; the airfoils use Venkatakrishnan. |
| `CFL_NUMBER` + `CFL_ADAPT_PARAM` | 1 to 1000, floors 1 to 100 | How large a step the solver takes. **Measured, not assumed** — see §7. |
| `MGLEVEL` | 0 or unset | No multigrid. |

### 3.2 The output settings we do change, and why

`SURFACE_CSV` carries **only the solution variables**. Skin friction, y⁺ and the pressure
coefficient reach a file only through the **Tecplot or ParaView surface writers**. A case written
with CSV alone can converge beautifully and still be ungradeable, because the quantity its
criterion is built on was never written. Two cases were in exactly that state until today
(§8). Every case now requests `SURFACE_TECPLOT_ASCII`.

## 4. The cases: what each one asks

Ten cases, in three groups. Nothing here touches an AERIS wing — this is **stage 0**, the work
that has to pass before a second solver is allowed near the actual design campaign.

### Group A — flat plates, against NASA's Turbulence Modeling Resource

The simplest wall-bounded turbulent flow there is. If a solver cannot get this right, nothing
downstream matters. NASA's TMR publishes converged CFL3D and FUN3D answers on the *same grids*.

| case | asks | grid | conditions |
|---|---|---|---|
| `fp_comp_137` | Does our SU2 setup reproduce NASA's compressible SA flat plate? | 13,289 nodes | M 0.2, Re/m 5e6 |
| `fp_comp_545` | The same on a **4× finer** grid — does refinement move it? | 209,825 nodes | M 0.2, Re/m 5e6 |
| `fp_inc_545` | The same again but **incompressible** — our actual regime | 209,825 nodes | Re/m 5e6 |

Criterion: skin friction at NASA's station x = 0.970084, and total drag.

### Group B — an airfoil, against the same resource

| case | asks | grid | conditions |
|---|---|---|---|
| `naca0012_inc_897` | Does it hold on a real airfoil with a pressure gradient? | 230,336 nodes | α 10°, Re 6e6, incompressible |

Criterion: CL within 1 %, CD within 2 %, CDv within 1 % of the TMR values
(CL 1.09094, CD 0.0122728, CDp 0.006067, CDv 0.0062059), with the compressible reference brought
to incompressible by Prandtl–Glauert (×0.9887).

### Group C — transition, which is the whole point

| case | asks | grid | conditions |
|---|---|---|---|
| `fp_bc` | Does the Bas–Cakmakcioglu model put **natural** transition in the right place? | 41,880 nodes | Re/m 3.34e6, Tu 0.18 % |
| `t3a` | Does Langtry–Menter reproduce **bypass** transition at high free-stream turbulence? | 68,129 nodes | Tu 5.9 % inlet, Re/m 198,944 |
| `t3a_minus` | The same at **low** turbulence, where transition happens much later | 123,617 nodes | Tu 1 %, Re/m 1.32e6 |
| `e387_sa_lm` | **The case that matters.** A low-Reynolds airfoil with a laminar separation bubble — AERIS's regime — with SA | 147,496 nodes | α 2°, **Re 200,000** |
| `e387_sst_lm` | The same airfoil and grid with SST, so the models can be compared directly | 147,496 nodes | α 2°, Re 200,000 |
| `nlf_sst_lm` | A natural-laminar-flow airfoil | 153,120 nodes | Re/m 4e6 |

**Why Eppler 387 is the important one.** At Re 200,000 the flow separates while still laminar,
transitions in the separated shear layer, and reattaches turbulent — a *laminar separation
bubble*. That is the mechanism that governs the outer panels of the AERIS wing, and it is exactly
what a fully-turbulent solver like ADflow cannot represent. McGhee's NASA TM-4062 gives both the
forces **and** oil-flow measurements of where the bubble starts and ends, so it grades the
mechanism and not only the totals.

## 5. Results

### 5.1 Verification — flat plates and NACA 0012

| case | cf error | CD error | verdict |
|---|---|---|---|
| `fp_comp_137` | **+0.77 %** | **+0.21 %** | passes |
| `fp_comp_545` | **+0.65 %** | **+0.32 %** | passes |
| `fp_inc_545` | **−0.04 %** | **+0.55 %** | passes |

**SU2 reproduces NASA's flat plate to under 1 % on both criteria, on three grids, compressible and
incompressible.** Refining 13k → 210k nodes moves cf by 0.12 points, so the answer is
grid-insensitive here. This is solid verification and it is the floor everything else stands on.

| case | CL | CD | CDp | CDv |
|---|---|---|---|---|
| `naca0012_inc_897` | +0.86 % | +1.75 % | +3.38 % | **+0.18 %** |

Lift passes its 1 % bar, total drag passes 2 %, friction drag is excellent at 0.18 %. **Pressure
drag is the outlier at +3.38 %** — and that is the same signature seen elsewhere in this project:
friction is easy, the pressure integral is where the error lives, because it is a small residual of
large cancelling contributions.

### 5.2 Validation — Eppler 387 against McGhee's measurements

Measurement uncertainty for this exact condition, from Table A1 of TM-4062: **±2.6 drag counts**
on CD, ±0.001 on CL.

| | CL | CD | pitching moment | separation bubble |
|---|---|---|---|---|
| **Measured** (α 2.04°, Re 200k) | 0.574 | 0.0118 | −0.0794 | x/c **0.43 → 0.67**, length 0.240c |
| `e387_sa_lm` (latest) | +0.96 % | **−2.16 counts** | −4.13 % | x/c 0.473 → 0.584, length **0.111c** |
| `e387_sst_lm` | +9.34 % | +37.2 counts | +9.2 % | **none** |

**These are snapshots of a solution that is still moving, and the movement matters.** SA-LM's
drag error across successive continuation legs has run **−12.7 → +0.71 → +0.36 → −2.16 counts**
against a ±2.6-count uncertainty. It is inside the band now, it has been outside it, and its
force is still changing 0.287 % per 500 iterations where the acceptance gate wants 0.05 %.

Quoting the friendliest snapshot would be easy and wrong. **What can be said today is that SA-LM
is landing within a few counts of the measurement and converging toward roughly −2**, not that it
predicts this case to 0.4 counts. The bubble length is firming up in the same way: 0.068c, then
0.111c, against 0.240c measured — still roughly half, still too short.

**SA-LM is the result worth having.** Lift within 0.4 %, drag **inside the measurement
uncertainty**, moment within 2 %, and it produces a laminar separation bubble **inside the measured
region**. Its one real error is that the bubble is **3.5× too short** — 0.068c against a measured
0.240c — which points at reattachment rather than at separation onset.

**SST-LM fails the same case on the same grid**: drag 37 counts high and no bubble at all, only
trailing-edge separation. The two models **disagree with each other by 37 counts**, and only one of
them is near the measurement. For AERIS that is a usable finding: if SU2 is used for transition,
it should be SA-LM.

Both runs are still short of the acceptance gate (§6) and are converging further as this is
written, so these numbers are provisional.

### 5.3 Transition location on flat plates

| case | onset | free-stream turbulence | expected |
|---|---|---|---|
| `fp_bc` | **Re_x 2.59e6** | 0.18 % | natural transition, ~2–3e6 ✓ |
| `t3a` | **Re_x 1.12e5** | 5.9 % inlet | bypass transition, ~1–2e5 ✓ |
| `t3a_minus` | **none found** | 1 % | should transition — see below |

Two of three land where the physics says they should. `t3a_minus` does not, and the reason is not
subtle: its skin friction **falls from the leading edge and then sits flat at about 2.0e-3 across
more than a decade of Re_x**, where a turbulent plate should decay from roughly 3.7e-3 to 2.1e-3
over the same span. A constant cf over that range is not a boundary layer of either kind. The run
is also unconverged. **This is flagged, not graded.**

`nlf_sst_lm` has stalled at rms −5.32 with its turbulence and transition equations never
converging at all, and produces no usable result.

## 6. The acceptance rule, and why one had to be written

SU2 had **no acceptance rule** in this project — only a residual target. That single fact is
responsible for most of what looked like failure.

`fp_comp_545` has been passing NASA's criteria **since 16 September** and was reported unfinished
for two days, because its residual sat at −8.63 instead of −14. Its **drag had been settled to
0.012 % over 500 iterations the whole time.** The residual target was never the question; the
quantity of interest was.

This project had already reasoned that out for ADflow on 15 September — accept on the residual
target **or** on settled quantities of interest, with health checks required either way, because a
short tail's spread is dominated by the approach rather than by the remaining error. Nobody
carried it across. `su2_gate()` is that rule, and it also states plainly when a case has **no
monitored force at all** — true of the three transitional plates, where SU2 writes CD identically
zero and the quantity of interest is cf, not drag.

| case | verdict | route |
|---|---|---|
| `fp_comp_137`, `fp_inc_545`, `fp_bc` | **ACCEPTED** | residual target |
| `fp_comp_545`, `naca0012_inc_897` | **ACCEPTED** | settled forces |
| `e387_sa_lm`, `e387_sst_lm` | not yet | still converging |
| `t3a`, `t3a_minus`, `nlf_sst_lm` | not yet | no monitored force |

**Five of ten**, against two before the rule existed. Neither case that changed hands was failing
physics.

## 7. What was measured rather than assumed

**The CFL floor is not the cause of the stalls.** Every stalled case has its CFL pinned at the
adaptation floor, which looked like the explanation — until two *converged* cases turned out to be
pinned at theirs too. A controlled probe, same restart and same iteration budget, floor as the only
variable:

| case | floor | orders per 1,000 iterations |
|---|---|---|
| `fp_comp_545` | **100 (control)** | **0.067** |
| `fp_comp_545` | 10 | 0.026 |
| `fp_comp_545` | 1 | 0.024 |
| `e387_sa_lm` | 40 (control) | **−0.068** (rising) |
| `e387_sa_lm` | 1 | +0.022 |

Lowering the floor makes the fine flat plate **2.5× worse** and is the only thing that stops E387
diverging. The two cases disagree, so **the CFL floor is a per-case setting, not a campaign-wide
fix.** E387 got floor 1 on this evidence; nothing else did.

**The pitching-moment sign.** The surface pressure of `e387_sa_lm` was integrated independently and
reproduced SU2's own pressure components to 0.9 % on CL, 3 % on CDp and 2.5 % on CMz — close enough
to trust the sign. In that convention a positive `M_z` lifts the **tail**, which is **nose-down**.
McGhee's −0.0794 is also nose-down, in a convention where nose-down is negative. **The same
physical moment, two sign conventions**, and the error in a common convention is −2.03 %.

## 8. Defects found and fixed, 16–18 September

Every one of these made a verdict mean less than it said. Several were found by feeding synthetic
inputs to the real functions rather than by reading the code.

| defect | effect |
|---|---|
| Transition onset from a global minimum | Reported a plate with no transition as transitioning at Re_x 2.6e8 |
| Convergence rate measured in history **rows** | SU2's write frequency is per case; called a stalled run "accelerating" three times |
| `SURFACE_CSV` only | `fp_bc` and `t3a` converged and were **judged on nothing at all** |
| `history()` read one file | Continuations invisible — and `queue23` had copied each **over** its original, so three cases' first legs no longer exist anywhere |
| `--restart` read `restart.dat` blindly | A *second* continuation would have rewound the case and discarded the first |
| `READ_BINARY_RESTART= NO` with a binary restart | T3A aborted on continuation; the format is now read from the file's own magic number |
| `abs(CMz)` vs `abs(CM_ref)` | Zero error for either sign; a genuine flip was invisible |
| Bubble from min/max of all reversed points | Merged separate regions into one fictitious span — **this is why both models were wrongly reported as producing no bubble** |
| `exit_success` from a string | A killed run reported as clean |
| **Re/m derived from the config** | **T3A and T3A− were 20.1× too high** |
| `forces_breakdown.dat` graded blindly | SU2 writes it when it chooses, not at the end; on E387 it was **2.27 counts stale** against a 2.6-count uncertainty |

The Reynolds one is the sharpest. Both T3A configs state their Reynolds number over the 20 m plate
and set `REF_LENGTH= 20.0` without a `REYNOLDS_LENGTH`, so a reader defaulting that length to 1.0 m
got 2.656e7 per metre where SU2 had used 1.32318e6. **SU2 prints the number it actually used.**
Across six cases the correction is exactly 20.1× on the two T3A cases and 1.0× on every other.

## 9. What this does and does not support today

**Supported:**

- SU2 reproduces NASA's turbulent flat plate to under 1 % on cf and CD, on three grids, in both the
  compressible and the incompressible path. *Verified.*
- SU2 reproduces the TMR NACA 0012 to 0.9 % on lift and 1.8 % on drag, with friction drag at
  0.18 %. *Verified.*
- **SA-LM predicts Eppler 387 at Re 200,000 to within the measurement uncertainty on drag, 0.4 % on
  lift, 2 % on moment, and produces a laminar separation bubble inside the measured region.**
  *Validated, provisionally* — the run is still converging.
- Transition onset on two flat plates lands where natural and bypass transition respectively
  belong.

**Not supported:**

- Any statement about SU2 on an **AERIS wing**. No converged SU2 solve on our own geometry exists.
  This is the gap that matters most and it is untouched.
- Any ADflow-versus-SU2 comparison. That needs matched geometry, grid, model and convergence, and
  none of those conditions is met yet.
- T3A and T3A− as *validation*. The ERCOFTAC server that holds Coupland's measurements refuses
  connections, and it is the only source. The runs are recorded so grading becomes a lookup when it
  returns.
- SST-LM for anything. It fails the one case where we have a measurement, by 37 counts.
- `nlf_sst_lm`. Stalled with its turbulence and transition equations unconverged.

**The honest one-line summary:** SU2's numerics are verified on the standard cases, its SA
Langtry–Menter path looks genuinely good in the low-Reynolds regime AERIS actually flies in, and it
has never been pointed at an AERIS wing.

## 10. What to do next with SU2

1. **Finish converging the two E387 runs** so the bubble result stops being provisional. In
   progress as this is written.
2. **Diagnose the T3A− flat cf.** It is a real anomaly, not a convergence detail.
3. **Run SU2 on one AERIS wing** at matched geometry, grid and model against ADflow. This is the
   whole reason for having it and it has never been done with a converged run.
4. **Decide whether transition enters the design dataset.** If SA-LM holds up, it changes drag by
   more than the design differences the campaign is trying to resolve — at which point a
   fully-turbulent dataset answers the wrong question.
