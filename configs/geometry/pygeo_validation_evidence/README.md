# pyGeo config-frame validation (roadmap step 1)

Numeric proof that the pyGeo backend reproduces the geometry an Aeris config
authors. Generated by `standalone/pygeo_validation/validate_config_frame.py`:

```bash
PYTHONPATH=src .venv/bin/python -m standalone.pygeo_validation.validate_config_frame \
  --config configs/geometry/paper1_bwb_pygeo.yaml \
  --check-controls-invariance \
  --report-dir configs/geometry/pygeo_validation_evidence
```

The harness is LIGHT: it builds only the neutral B-spline loft and slices it
(no physical CAD / STEP / STL / exports), so it is safe to run in-session.

## Two-tier result

**GATE (physically required — sets PASS/FAIL):** 4/4 pass on
`paper1_bwb_pygeo.yaml`.

| gate | result |
|---|---|
| ASB-frame reconstruction residual | 6.6e-16 (machine eps) |
| reference area vs planform | +5.7e-5 (0.003%) |
| reference span vs planform | +1.4e-4 (0.004%) |
| reference aspect ratio vs planform | +2.7e-4 |
| control-surface invariance of neutral loft | 0.0 m deviation |

**CHARACTERIZATION (measured, NOT gated):** the kSpan=3 B-spline loft
*approximates* — does not interpolate — the 17 authored stations. Worst-case
smooth-loft envelope on the production config:

| deviation | max |
|---|---|
| chord (relative) | 1.18% |
| twist | 0.40° |
| LE position | 8.4 mm |

The deviation is smooth and sign-consistent (twist over-rotates the tip and
under-rotates inboard; chord runs slightly full inboard), so it cancels in the
integral — hence the near-exact reference metrics. Max LE 8.4 mm sits inside the
previously recorded 19.1 mm Hausdorff for this loft family.

## Modelling decision — RESOLVED (Mike, 2026-07-24)

**The smooth MACH-Aero pyGeo B-spline loft is the master geometry** ("keep the
spline of mach aero and use this approach in aeris"). The piecewise Aeris station
stack is control input only; the loft is NOT re-parameterized to interpolate it.

Therefore:
- The **GATE above IS the step-1 validation** and it PASSES.
- The pointwise deviation (chord 1.18%, twist 0.40°, LE 8.4 mm) is a **characterized
  property of the master surface**, living in the design-variable space — not a
  defect. It is reported honestly, not tuned away.
- Aero (AVL/NeuralFoil) and mesh already extract from the realized surface, so the
  whole pipeline is consistent with this master.

Endpoint check: the realized root twist (0.299° where authored root = 0°) was
confirmed a **smooth B-spline end offset** (0.299 → 0.216 → 0.047 → −0.215 across
span fractions 0 → 0.06), not a spike — the master surface is well-formed at its
root.

See `memory/project_master_geometry_decision.md`.

## Step 2 — wide-bound smoke DoE

`paper1_bwb_pygeo_smoke_doe_doe.md` records a 24-design sweep over WIDE bounds
(`configs/geometry/paper1_bwb_pygeo_smoke_doe.yaml`, seeds 3000..3023): **24/24
built + gate-pass** in ~22 s. Reference-metric reproduction holds across the space
(area rel err max 4.0e-4); the smooth-loft envelope stays bounded (chord p95 1.68% /
max 1.88%, twist p95 0.49° / max 0.55°, LE max ~12 mm) — consistent with the single
production point, confirming the master-loft path is robust.
