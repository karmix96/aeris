01
Geometry layer
Config YAML → deterministic aircraft. One geometry = one airplane realization. Modular generator registry.
02
Dataset layer
N geometries via LHS sampling. Each gets its own folder under data/datasets/. Reproducible by seed.
03
Aero layer
AVL via AeroSandbox. Single operating point or Cartesian sweep (α, β, V, alt, p, q, r). Writes aero_result.json per case.
04
QC + Curation + Promotion
Three successive gates. Only promoted datasets may enter ML. Raw and curated-only are rejected at the gate.
05
ML layer
Tabular surrogate baseline: CL, CD, CM. Features = design params + flight condition. Seeded splits, grouped by geometry_id to prevent leakage.
QC presets — pick one
off
No QC runs. Data passes silently. Debug mechanics only — never for real data.
debug
Geometry + aero QC with basic profile. Failures logged but pipeline continues.
production
Basic profile. QC failure stops workflow. Default for daily batch runs.
promotion_strict
Strict profile. Hard stop on failure. Use only for promotion / ML / curated releases.

End-to-End CLI

// geometry → dataset → aero sweep → QC → curate → promote → ML train
Step 1 — Sanity check
aeris version aeris pipeline smoke -c configs/geometry/baseline_bwb.yaml
Step 2 — Generate a dataset (N geometries)
aeris dataset generate \ -c configs/geometry/wing_bwb.yaml \ --n 200 \ --sampler lhs_v1 --sampler-seed 123 \ --no-save-plot \ --name run_n200_lhs123 aeris dataset inspect --dataset data/datasets/run_n200_lhs123
Step 3 — Aero sweep across the dataset
# Run sweep for each geometry in the dataset aeris aero sweep \ --dataset data/datasets/run_n200_lhs123 \ --geometry-id geom_00001 \ --velocity 28 --altitude 0 \ --alpha-values "0,2,4,6,8,10" \ --beta-values "0" # Inspect result latest_sweep="$(ls -td data/runs/*_aero_sweep_* | head -n 1)" aeris aero sweep-inspect --run-dir "$latest_sweep"
Step 4 — Curate the aero dataset
aeris curate-aero \ --dataset data/datasets/run_n200_lhs123 # → curated_aero_dataset.csv + curation_report.json
Step 5 — Promote (strict gate)
aeris promote-aero \ --dataset data/datasets/run_n200_lhs123 \ --qc-preset promotion_strict # → promotion_manifest.json (blocks ML if not passed)
Step 6 — Train ML surrogate
aeris ml train \ --dataset data/datasets/run_n200_lhs123 \ --features span,aspect_ratio,alpha,velocity,altitude \ --targets CL,CD,CM \ --model random_forest \ --seed 42 # → model + RMSE/MAE/R² + config snapshot
Single geometry + single aero run
aeris geometry generate -c configs/geometry/baseline_bwb.yaml aeris aero run \ --config configs/geometry/baseline_bwb_25.yaml \ --geometry-source native \ --alpha 4 --beta 0 --velocity 28 latest_run="$(ls -td data/runs/*_aero_* | head -n 1)" aeris aero inspect --run-dir "$latest_run"
ML training data interface
aeris dataset training-data \ --dataset data/datasets/run_n200_lhs123 # Loads promoted data, validates schema, # returns X / y / metadata
Useful shell helpers
# Latest dataset latest_ds="$(ls -td data/datasets/* | head -n 1)" wc -l "$latest_ds/metadata.csv" wc -l "$latest_ds/failures.csv" # Dataset audit python scripts/generic/audit_dataset.py
