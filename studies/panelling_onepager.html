How coarse a wing mesh can we trust?

We will call AVL (a fast aerodynamics tool) thousands of times to search wing shapes. Each call needs a mesh of panels on the wing. Fine mesh = accurate but slow. Coarse mesh = fast but can be wrong. This study finds the coarsest mesh that still gets the decisions right.

How we measure "accuracy" with no CFD

There is no wind-tunnel or CFD "truth" here. So we run the densest AVL mesh we can afford (chord 48 × span 2, ~5,400 panels) and treat it as the reference. "Error" = how far a coarser mesh drifts from that dense mesh. Catch: the dense mesh is itself ~1.5% off reality on elevon power, so our errors are a self-consistency check — an optimistic floor, not absolute truth. Anything needing true <1% accuracy needs a better tool than AVL.

What the panels buy you

The control-deflection part (why, in one line)

We tested with the elevons deflected (a busier, harder flow) even though the aircraft normally flies with them neutral. Logic: if a mesh is good enough for the hard case, it is good enough for the easy one. We then re-checked at zero deflection and the design ranking was identical — so the choice of mesh does not depend on how the elevons are set.

The gates — the trust checklist

A cheap mesh is only allowed if it passes all seven checks against the dense mesh, on all 30 designs. In plain words:

1 Rank

Same ordering. Does it sort the designs best→worst the same way? PASS all

2 Top 10

Same shortlist. Are the best 10 designs still the best 10? PASS (except the toy-cheap one)

3 Winner

Same pick. Is the design it calls #1 as good as the true best? PASS all (0% regret)

4 Numbers

Accurate coefficients. Are CL, CD, Cm, xnp within 1% of the dense mesh, worst-case? FAIL all — even production is ~3% out

5 Controls

Right control effect. Do the elevon effects have the right sign and size (within 5%)? PASS all

6 Decision

Same flying call. Same trim angle (within 0.5°), same stable/trimmable labels? On the line at c16, FAIL below

7 Ran

It worked. Did 100% of solves succeed? PASS all

The rule: pass all seven → use the cheap mesh. If none pass, do not lower the bar — report that the model needs to be finer. That is what happened.

What to take away

USE

Ranking a big design sweep? Use c16s2u. It sorts designs correctly, picks the same winners, and is 7× faster than the production mesh (19 h vs 140 h). This holds whether the elevons are deflected or not.

DON'T

Need exact drag / elevon power / trim numbers? No AVL mesh here is within 1%. Even the expensive production mesh is ~3% off the dense reference (and the reference is ~1.5% off reality). Treat absolute control numbers as ballpark, not final.

THEN

If a <1% absolute number is truly required → go beyond AVL. The vortex-lattice model is at its resolution limit for control-surface loading; that needs a higher-fidelity (CFD-grade) treatment, not just more AVL panels.
