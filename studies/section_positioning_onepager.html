Section placement: pin the important spots, space the rest evenly

AVL builds the wing from a set of cross-sections and draws straight lines between them. Question: should we bunch sections up where the shape is complicated (an "adaptive" rule), or just spread them evenly? Answer: spread them evenly — but always put a section exactly on the few must-hit spots.

How we checked it without CFD

No wind tunnel here. So we ran AVL with a very dense set of sections (201) and checked it had stopped changing as we added more (it changes <0.5% from 151→201). That dense result is our "truth." Then we measured how far coarser section layouts drift from it. Key fix vs the last study: the old study compared against a not-dense-enough reference that quietly favoured even spacing — we proved ours is converged first.

What to do

DO

Space sections evenly, and always pin the must-hit spots — the elevon band edges, the planform (sweep/taper) breaks, and the fixed-airfoil stations. This is one setting: keep "snap to control" ON, turn "adaptive placement" OFF.

DON'T

Don't bunch sections by geometric complexity. It reliably makes things ~2× worse — it crowds the busy spots and starves the smooth, still-loaded parts of the wing. The earlier "adaptive is better" result was really the pinning helping, not the bunching.

NOTE

Use ~25 sections for screening, ~49 when control numbers must be tight. Two quantities (induced drag, hinge moment) stay ~2% off regardless — that's an AVL limit, not a layout you can fix.
