Important fixes covered

1. views.py
- Removed silent NACA0012 fallback on missing/corrupt airfoil files.
- Added explicit reconstruction artifact version metadata.
- Added geometry validation for:
  - monotonic span stations
  - finite coordinates
  - positive chord
  - minimum section count
- Tightened native airplane extraction behavior.

Why this matters:
Silent fallback was the nastiest issue in the batch. It could quietly corrupt aerodynamic fidelity and poison later dataset / ML work.

2. aerosandbox_avl.py
- Added geometry reference-quantity validation before solver execution.
- Added explicit AVL executable resolution and clean failure if not found.
- Added Mach/velocity consistency warning instead of pretending both are authoritative.
- Kept structured failure behavior.
- Added AVL paneling context protection to avoid global-state leakage.

Important note:
The first implementation of the AVL paneling context was not fully safe because it restored the top-level defaults object by reassignment, while nested mutable state had already been mutated. That caused the test
`test_avl_paneling_context_restores_global_defaults`
to fail.

Final fix:
- restore AVL defaults in place using:
  - clear()
  - update(deepcopy(snapshot))

Why this matters:
This is important for reproducibility and future parallel execution. Global mutable solver configuration is exactly the kind of bug that behaves politely in small runs and then stabs you later.

3. sweep.py
- Added case-count helper.
- Added guard against combinatorial blow-up with max_cases.

Why this matters:
Prevents accidental explosion of sweep size from Cartesian products.

4. sweep_io.py
- Sanitized/shortened case labels.
- Added summary counts:
  - success
  - invalid_output
  - solver_failed
  - invalid_input
  - failed_total

Why this matters:
Makes sweep manifests actually useful for auditing and not just decorative JSON.

5. sweep_run.py
- Added progress printing.
- Added optional max_cases guard path through orchestration.
- Added aggregate runtime tracking in summary.

Why this matters:
Improves operator visibility and gives the sweep manifest actual operational value.
